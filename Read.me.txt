# ESP32 Light Switch

A little ESP32 and servo that flips my light switch from anywhere, using a web page I built on Cloudflare.

I got tired of getting up to turn the light off, and I didn't want to rewire anything or touch mains power. So I put a servo next to a normal wall switch and taught it to flip the switch when I tap a button on my phone. It works from the other side of the house, or from another city.

This project actually started as a way to press my PC's power button remotely. Once it worked, I pointed it at a light switch instead, and it turned out to be even more useful.

## What it does

- Open a web page, tap **Light ON** or **Light OFF**, and the servo flips the switch.
- Works over the internet, not just on your home WiFi.
- Starts with a small animated "Hello, how are you?" intro, with sound, before showing the controls. It isn't needed, but I like it.
- Nothing inside the wall is touched. The servo only pushes the plastic rocker from the outside.

## How it works

There are three parts:

1. **The web page** is hosted for free on a Cloudflare Worker. When I tap a button, the page sends an `on` or `off` command to the Worker.
2. **The Worker** saves that command in Cloudflare KV, a small key-value store. Each command gets an ID and a timestamp, and it expires after 30 seconds so an old command can never fire late.
3. **The ESP32** asks the Worker for the latest command every 3 seconds. When it sees a new ID, it moves the servo to push one side of the rocker, then returns to center.

Because the ESP32 calls out to the Worker, you don't need to open any ports on your router or set up port forwarding.

## What you need

| Part | Notes |
|---|---|
| ESP32-S3 board | Any ESP32 board should work with small changes |
| Servo | I used an MG995 (large metal-gear servo). An SG90 or MG90S also works for light switches and is easier on power |
| Double-ended servo horn | The straight bar that comes with the servo |
| USB charger | 5V, 2A recommended |
| 2.4 GHz WiFi | The ESP32 can't connect to 5 GHz networks |
| Free Cloudflare account | For the Worker and KV |
| Tape, glue or a bracket | To hold the servo steady beside the switch |

Optional: a 470-1000 µF capacitor across the servo's power wires, and 4xAA batteries if the ESP32 resets when the servo moves.

## Wiring

| Servo wire | Connects to |
|---|---|
| Signal (orange/yellow) | ESP32 GPIO 4 |
| Power (red) | 5V (see the power note below) |
| Ground (brown/black) | ESP32 GND |

**Power note:** big servos like the MG995 draw a lot of current when they move. If the ESP32 restarts or the servo twitches, power the servo from a separate source (4xAA batteries or a second USB charger) and **join its ground to the ESP32 ground**. The grounds must be connected or the servo won't respond properly.

## Setup

### 1. Cloudflare

1. Create a free account at cloudflare.com.
2. Go to **Workers & Pages**, create a new Worker, and give it a name.
3. Open the code editor, delete the sample code, and paste in `worker/worker.js`.
4. Change `DEVICE_KEY` at the top to your own long, random string.
5. Go to **Settings > Bindings > Add > KV namespace**. Create or choose a namespace, and set the **variable name to exactly `KV`**. This is the step that causes most errors if the name is different.
6. Click **Deploy**. Your control page is at `https://YOUR-WORKER.YOUR-SUBDOMAIN.workers.dev`.

### 2. ESP32

1. Install the **ESP32Servo** library from Arduino IDE's Library Manager.
2. Copy `esp32/secrets.example.h` to `esp32/secrets.h` and fill in your WiFi name, WiFi password, the same `DEVICE_KEY` as the Worker, and your Worker URL.
3. Select your board (ESP32S3 Dev Module) and the correct COM port.
4. Upload `esp32/esp32.ino`, then open Serial Monitor at 115200 baud.

### 3. Mounting

1. Power the ESP32 once so the servo moves to its center position (90 degrees).
2. Press the horn onto the servo shaft so the bar is level, with one end pointing at the switch rocker.
3. Fix the servo firmly beside the switch plate. It must not move when it pushes.
4. Adjust `ON_ANGLE` and `OFF_ANGLE` in `esp32.ino` until the arm flips the rocker cleanly. Change them 5-10 degrees at a time.

## Tuning

- If the arm pushes the wrong side, swap `ON_ANGLE` and `OFF_ANGLE`.
- If it doesn't reach the rocker, lower `ON_ANGLE` and raise `OFF_ANGLE` a little, or move the servo closer to the switch.
- If the servo buzzes or strains at the end of its swing, the arm is pressing against the switch plate. Reduce the angle.
- At boot, the servo moves to both angles once, so you can check the swing before using the web page.

## Troubleshooting

| What you see | Likely cause |
|---|---|
| Upload fails with "Failed to connect" | Wrong COM port, charge-only USB cable, or the board needs boot mode (hold BOOT, tap RESET) |
| Serial Monitor shows nothing | Set **USB CDC On Boot > Enabled** and upload again |
| ESP32 can't connect to WiFi | Wrong password, or a 5 GHz network. Use 2.4 GHz |
| `HTTP 401` in Serial Monitor | `DEVICE_KEY` in the ESP32 doesn't match the Worker |
| `HTTP 500`, or the web page shows "Worker threw exception" | The KV binding is missing or isn't named `KV` |
| Page says "Sent" but the servo doesn't move | Check the GPIO 4 wire, servo power, and the shared ground |
| ESP32 restarts when the servo moves | Power problem. Use a separate supply for the servo |

## Good to know

- **There's a small delay.** Cloudflare KV isn't instant everywhere, and the ESP32 checks every 3 seconds, so a tap can take a few seconds (occasionally longer) to reach the switch.
- **Old commands are ignored.** The ESP32 ignores whatever command is waiting when it boots, and commands expire after 30 seconds, so a reboot can't flip the switch by itself.
- **The page has no password.** Anyone with the link can flip the switch, so don't share the link. If you want more security, add a password check to the Worker.
- **Your secrets stay private.** `secrets.h` is listed in `.gitignore`, so your WiFi password and device key never reach GitHub.

## Safety

This project is low voltage only. **Don't open the switch plate or touch any wiring behind it.** That's mains electricity. The servo only pushes the plastic rocker from the outside.
